# Multimodal Awakening - 多模态能力自动唤醒框架

> 让大模型自动识别并处理用户发送的各种媒体文件

## 🎯 一句话介绍

**MCA（Multimodal Capability Awakening）** 是一个通用的多模态处理框架，通过标准化媒体引用标记 `[media:type:path]`，让任何支持工具调用的 OpenClaw Agent 自动识别并处理图片、音频、PDF、视频、表格等多种媒体格式。

## ✨ 核心特性

- 🖼️ **自动图片分析** - 支持单图/多图对比、OCR、场景识别
- 🎵 **语音自动转写** - 语音消息自动转文字并摘要
- 📄 **PDF 智能提取** - 文档内容提取、摘要生成
- 📊 **表格数据分析** - Excel/CSV 数据分析和可视化建议
- 🎬 **视频内容理解** - 关键帧提取和内容分析
- 🔄 **动态工具适配** - 自动检测可用工具，智能降级
- 🌐 **渠道无关** - 支持飞书、Discord、Telegram 等所有渠道

## 🚀 快速开始

### 安装

```bash
# 方式1：复制到 skills 目录
cp -r multimodal-awakening ~/.openclaw/skills/

# 方式2：使用 openclaw CLI
openclaw skills install multimodal-awakening
```

### 配置 Gateway 层

在你的渠道插件（如飞书插件）中添加媒体拦截器：

```javascript
// 伪代码示例
if (message.type === 'image') {
    const localPath = await downloadImage(message.image_key);
    message.content = `[media:image:file://${localPath}]${userText || ''}`;
}
```

详见 `scripts/gateway-interceptor.js` 完整示例。

### 使用

安装后，直接发送媒体文件即可自动处理：

```
用户: [发送图片]
系统: 自动分析图片内容并返回结果

用户: [发送语音]
系统: 自动转写语音并摘要

用户: [发送 PDF]
系统: 自动提取文档内容
```

## 🛠️ 支持的媒体类型

| 类型 | 标记 | 优先工具 | 降级方案 |
|------|------|---------|---------|
| 图片 | `image` | `image` | Python + PIL/OCR |
| 音频 | `audio` | - | Python + Whisper |
| PDF | `pdf` | `pdf` | Python + PyPDF2 |
| 表格 | `sheet` | - | Python + pandas |
| 视频 | `video` | - | Python + ffmpeg |
| 代码 | `code` | `read` | Python 解析 |

## 🔧 工具发现机制

本框架会自动检测当前环境可用的工具：

```python
from scripts.tool_discovery import ToolDiscovery

discovery = ToolDiscovery()

# 检查特定工具
if discovery.has_tool('image'):
    # 使用原生 image 工具（需要模型支持 vision）
    process_with_native_tool()
else:
    # 使用 Python 降级方案
    process_with_python_script()
```

## 💡 为什么需要 MCA？

### 问题：大模型的"能力沉睡"

多模态模型（如 GPT-4V、Claude 3、Kimi k2.5）具备处理图片/音频/PDF 的能力，但：
- 用户发的图片，模型不知道可以用 `image` 工具处理
- 用户发的语音，模型不知道可以转写
- 需要用户显式指令："请分析这张图片"

### 解决：MCA 框架

通过 Gateway 层自动注入媒体标记，Agent 层自动检测并调用对应工具，实现：
- ✅ **零摩擦体验** - 用户直接发文件，系统自动处理
- ✅ **智能降级** - 模型不支持时自动切换到 Python 方案
- ✅ **渠道无关** - 一套代码适配所有渠道
